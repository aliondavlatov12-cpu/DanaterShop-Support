# DanaterShop Support

AI support bot for @DanaterShop_SupportBot.

## Render

Build:
pip install -r requirements.txt

Start:
python support_bot.py

## Environment Variables

SUPPORT_BOT_TOKEN
DATABASE_URL
GROQ_API_KEY
AI_MODEL
ADMIN_IDS
PORT

The bot uses the same Neon PostgreSQL database as the main DanaterShop bot.
